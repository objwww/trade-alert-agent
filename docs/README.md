## 需要优先审阅的决定

- 第一闭环采用“订单实例退出导致下单失败”；其余场景有明确前置条件，全部仍未执行。
- 同一 Incident 可有多个独立 Run，结果分别保存；当前报告由显式授权选择，不采用最后写入覆盖。
- 每个 Run 同时只有一个有效 Owner；Run 内 Task 可并行；StateCommitter 不把所有 Run 放进全局串行锁。
- 生命周期、执行阶段、证据覆盖、根因结论及业务恢复分开；终态不因迟到回调复活。
- 结构合法与引用存在不证明因果；缺证允许 INCONCLUSIVE，审核接受不授予重启／回滚权限。
- 真实身份、预算、Epoch 与资源权限由服务端控制；场景真值与评判答案不进入被测 Agent。
- 模块化单体、薄 Harness 和 PostgreSQL 是本轮提出的设计决定；Spring AI Alibaba／Temporal 的复用和替换条件已列明。
- RCA 与谷粒商城兼容栈及数据库分离；具体 BOM、模型提供方、环境及容量须在相应目标实施前核实。
