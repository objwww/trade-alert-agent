## 2. 本轮独立核验与终裁

| 质疑 | 独立核验 | 裁决及依据 |

## 3. 工具配置迁移裁决（配置尚未安装到仓库）

- 只用 Ruff format/check，不另设 black；Python target py312；行宽 100 是项目自定，不归因于 Paddle。
- mypy 采用全局 strict，覆盖新写源码及测试；pytest 测试函数返回 `None`，fixture 参数/返回值、辅助函数均须注解；异步测试返回注解同样为 `None`。不增加 `tests.*` 的整体放宽 override。
- 第三方无类型依赖如确需例外，限定具体模块、错误码、原因及复审条件，不使用全局 ignore_missing_imports。
- 最终 Ruff 规则集、兼容性、版本及 uv.lock 在正式合并迁移/首个工程方案中用正反探针核验；不得以空包通过替代实际测试模块通过。四入口实跑目前未完成。
- Ruff/mypy 不足以证明金额和时间的业务语义。证据规划：`tests/coding/test_money_contract.py` 验证 Decimal 字符串序列化、币种、quantize 舍入；`tests/coding/test_time_contract.py` 验证耗时使用注入单调钟。AST 规则仅覆盖定义清楚的语法模式，变量来源和别名追踪须承认漏检，以边界类型、行为测试和审查补足。
- 仅对明确要求可哈希的值对象验证哈希；不是每个 dataclass 都应可哈希。frozen 不代表深不可变，不滥用 unsafe_hash。

## 5. 来源张力与其他修正

- 黄山版最小货币单位整数存储与本项目 Decimal 精确计算不是同一承诺；不据它推导 Decimal 持久化表示。计算用 Decimal 的既有裁决不变，存储/接口编码与商城舍入由 MVP 核验。黄山原文该项本轮未独立抽取，只登记 DeepSeek 报告及待复验状态。
- 已独立读 BBP-1015：内部函数优先异常；API-08 在协议边界映射稳定 error_code，与内部不返回错误码并不冲突。
- detect-private-key 属工具钩子名称，不是 secguide 指定要求；未选用前不扩展 CI。
- Kitex 熔断材料不能直接证明 asyncio Semaphore/Queue 的项目参数；有界并发、超时、资源耗尽策略需引用 Python 官方机制和既有项目资源约束。
- BBP-1017 的示例确有 except Exception 并记录异常，不等于允许吞异常；禁 bare except 与边界异常分类写为项目强化要求。
- 不接受“所有队列满则拒绝”的无条件简化；须服从既有 P0 不静默丢弃及持久化/升级策略。
- import-linter 不成为第五个 CI 入口，不能把 import-linter 当命名后缀的检查器。
- 接口最小 HTTP 面尚未批准：外部存活探测不必然要求 HTTP；鉴权审计也不必然要求 HTTP 静默/ack 接口。不借调研扩大 MVP。
